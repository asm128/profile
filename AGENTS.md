# Site portability

This site must remain usable when its folder moves or it is hosted under a different repository or domain.

- Link site-owned pages, articles, scripts, styles, images and other assets with relative paths.
- Cite material owned by an external source repository with its direct canonical URL.
- Do not add absolute machine paths, assume a fixed site host, or copy/add a source repository or submodule solely to make a citation resolve.
- If a site-owned relative target is missing from this copy, report the missing target. Do not substitute an unrelated article tree, copy content from another site, or hardwire the previous host.
- Preserve historical evidence and article content unless the assigned task explicitly authorizes changing them.
